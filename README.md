# Petstore → PostgreSQL
Учебный проект получает данные о доступных питомцах из Petstore API через HTTP GET-запрос и сохраняет их в PostgreSQL.

Пользователь вводит количество питомцев для обработки. Программа отправляет запрос к API с параметром status=available, 
преобразует JSON-ответ в объекты Python и выбирает не больше указанного количества питомцев.

В таблицу pets сохраняются поля id, name и status. Если питомец с таким ID уже существует, программа обновляет его имя и статус.

Программа состоит из трёх функций:

ask_pet_count() — запрашивает положительное целое число и повторяет ввод при ошибке.

get_available_pets(count_pets) — получает данные из API, проверяет ID и возвращает список питомцев.

save_pets(available_pets) — сохраняет питомцев в PostgreSQL и возвращает количество обработанных записей.

Программа обрабатывает HTTP-ошибки, ошибки сети, подключения и записи в PostgreSQL, а также некорректные значения.
